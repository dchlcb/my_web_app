1. 项目介绍
    本项目是一个基于C++的CTC应用程序，主要用于实现CTC协议的解析和数据处理。该项目包含了CTC协议的基本功能模块，并提供了相应的测试用例。
2. 项目结构
    - src/：源代码目录，包含CTC协议的实现代码
    - build/：编译输出目录，包含编译生成的中间文件
3. 脚本介绍
    - build_project.sh：编译脚本，用于编译项目
    - run_program.sh：程序运行脚本，需要上传到开发板，用于运行程序
    - upload.sh：上传脚本，用于将编译好的程序上传到开发板
4. 程序编译方式：
    在终端下执行"./build_project.sh -arm"命令，即可完成arm开发板程序的交叉编译，编译完成后的二进制可执行文件在当前目录下
